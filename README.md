# Kuyumcu Kar Takibi — TAM SÜRÜM

Özellikler:
- Satış ve alış
- Çeyrek / yarım / tam / Ata / Gremse
- Bilezik, temiz ürünler, 14/22 ayar fantazi
- 22 ayar gram: 100 TL/adet alış ve satış
- Gümüş takı satış: 100 TL/gram
- Alış: normal maliyet - müşteriye verilen tutar
- Günlük toplam TL ve has gramı
- Kayıt düzenleme ve silme + silme onayı

Kurulum:
1. Bu klasörü aç.
2. Aynı klasörde terminal aç.
3. `python3 -m venv .venv`
4. `source .venv/bin/activate`
5. `pip install -r requirements.txt`
6. `streamlit run app.py`
